# uzi-0.5-t2

Esse é um bot experimental criado em base da personalidade de um personagem de uma serie de animação indie chamada "Muder Drones", é um bot apenas para entreterimento para a comunidade da serie e nada das informações que é passada é real, não leve a sério quaisquer comentarios dele. Os comandos não estão explícitos, consulte o código para saber quais são os comandos.
